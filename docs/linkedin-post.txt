I've been working on DataScope, a portfolio project that brings together the parts of data work I want to demonstrate: cleaning records, querying them with SQL, checking their quality and presenting the results clearly.

The project explores job adverts for UK data roles. Python validates and classifies the records, DuckDB stores observations by date, and a six-page dashboard lets users compare role families, skill combinations, locations, working arrangements and advertised salary ranges.

Some of the decisions behind the dashboard:

• Count each advert once per observation date.
• Keep contract day rates separate from annual permanent salaries.
• Show missing-data coverage and small salary samples.
• Keep hybrid and fully remote roles separate.
• Explain the calculations and how every page connects to the data.

The current demo uses clearly labelled synthetic data. It demonstrates the workflow; it isn't a report on today's UK labour market. CSV import and an optional Adzuna connector are included for working with real source data.

The project has 29 passing automated tests, covering the Python pipeline, calculations, browser interactions and accessibility checks. I used AI-assisted implementation and documented the rules, tradeoffs and tests so the work can be inspected and reproduced.

I'm looking for opportunities in data analytics and would welcome feedback on the project and the decisions behind it.
